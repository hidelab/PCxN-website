          About

          The question this tool answers: which pathways correlate with the one you are studying?

          PCxN Explore rebuilds the old "top N neighbors" view as static files. Start from Search/Select Pathways by List/Browsing, Search/Select Pathways by Keyword, or Search/Select Pathways by Gene List, then Build network — the page fetches each selected pathway's slice, ranks their combined topN neighbors, and draws the induced graph. Nodes are colored by which group they came from; discovered neighbors are blue.

          Sliders re-filter the current result without another fetch, using absolute correlation (|r|) and FDR. A single-pathway query will lower the correlation cutoff if fewer than Top N FDR-significant partners exist, and show a banner on the network. Click a node to highlight its neighborhood. Use Pathway names Short or Full, Size, and Font on the graph. Search genes in network opens a panel above the graph so you can overlay genes of interest (brown ring) and see the result immediately. The URL keeps the query (including every group and pathway) so you can send someone the same neighborhood.
